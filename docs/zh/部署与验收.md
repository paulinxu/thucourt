# 部署与验收

## 本地演示

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r backend/requirements.lock.txt
cp .env.example .env
python backend/manage.py migrate
python backend/manage.py seed_demo
python backend/manage.py runserver 8000
# 另一个终端
cd frontend && npm install && npm run dev
```

打开 `http://127.0.0.1:5173`，使用 `alice / court-demo-2026`。切换 `bob` 可以测试消息和比赛确认；`pending` 会被引导到身份审核；`admin` 可打开身份审核页面或 `/admin/`。本地默认 SQLite、Celery eager 和离线 AI，文件在 `backend/private_media/`。

## 自动检查

```bash
python -m pytest --junitxml=artifacts/backend-tests.xml
ruff check backend
ruff format --check backend
cd frontend && npm run build && npm audit
```

`docker compose up --build` 使用 PostgreSQL、Redis、Gunicorn、Celery 和 Nginx；部署前必须准备生产 `.env`，设置随机密钥、域名、HTTPS 反向代理、人工审核方式和模型同意政策。Docker worker 需要 FFmpeg。

## 手工验收清单

1. 未登录或 pending 账号访问 `/api/players/` 得到 403；审核通过后可访问。
2. 配置页有 2 个区域、4 个日期和 14 个时段；紫荆/北馆买卖网格为 14/4 列，约球为 1 列。
3. 发布转场、求场、换场、约球；筛选、联系、完成/取消和创建者删除可用，其他人不能删除。
4. 两个账号在无好友关系时互发消息；同一个 `client_id` 重试不会重复。
5. 提交单打或双打；确认次数不足时积分不变，最后确认只更新对应轨道一次。
6. 好友提交匿名星级和技术反馈；另一账号看不到反馈，目标本人能在球友圈/教练看到。
7. 上传合成照片；离线模式显示校验/抽帧完成但不会声称视觉理解；生成计划后点击保存，其他账号不能读取。
8. 开启远程模式前配置 API Key、模型、HTTPS 和用户 AI 同意；模型服务故障应显示失败和重试，不应出现伪造计划。
