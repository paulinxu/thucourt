# THUCourt 课程方案总览

## 项目定位

清网同行（THUCourt）服务清华大学已认证的学生网球用户。第一阶段解决三件事：闲置网球时段交换、寻找合适球友、根据真实反馈形成私有训练建议。网站先行，微信小程序作为复用同一 API 的后续客户端。

## 需求中采用的明确规则

双打必须由提交者之外的三名参赛者全部确认；确认后比赛不可更正。技术反馈各项使用 1–5 分。场地预约转让、交换和付款发生在线下，平台不冒充大学预约系统。身份材料只交给审核管理员；输入真实姓名和学号本身不会自动认证。

## 尚未接入外部服务的边界

微信网站登录需要开放平台应用凭据；远程 AI 需要服务商 API Key 和模型名。没有凭据时，网站仍可用合成演示数据和明确标识的离线规则教练完成课程验收；离线模式不会宣称理解照片或视频。
