# 实现复盘与成员分工

## 本次实现

项目从原设计文档开始补齐了可运行的 Django + React 单体仓库：后端按账户、场地、社区、比赛和教练模块拆分；前端按账户、首页、集市、球友、比赛和教练页面拆分。领域服务集中处理权限、积分和 AI 证据，避免把规则散落在页面或模型调用中。

## 验收结果

后端测试 73 个通过，覆盖正常和恶意输入；1 个 PostgreSQL 行锁竞态测试在 SQLite 本地跳过。前端 `npm run build` 成功，`npm audit` 在依赖更新后无漏洞。由于当前环境没有可用浏览器下载源，未执行 Playwright 浏览器实测；接口、前端类型检查和生产构建已完成。真实微信 OAuth 和远程模型调用需要部署凭据后再做一次环境验收。

## 建议的课程小组分工

- **产品/项目负责人**：需求确认、演示脚本、学生身份审核流程、场地规则与课程材料。
- **后端负责人**：Django 模型、API、权限、比赛积分、迁移、后台和测试。
- **前端负责人**：React 页面、移动端样式、消息/网格/教练交互和可用性。
- **AI/部署负责人**：提示词与证据边界、媒体处理、模型评估、Docker、日志和成本控制。

一人小组可以按上述四个角色阶段性完成；提交报告时应按实际贡献修改姓名和比例，不要直接把这份建议当作事实。
